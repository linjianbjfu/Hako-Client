# Audit decision records by continuing value

Read the relevant sections of [the Hako project reference](../../references/hako-project.md) and the affected sources.

Inventory the requested note/doc locations and their local conventions. Hako currently has no mandatory Agent Note corpus or sealed translation-triplet system. If no records exist in scope, report that result; do not manufacture directories or notes to complete an archive task.

For each record, compare its claims with current sources, later decisions and inbound references. Age and length are search aids, not reasons to archive. Keep rationale about process separation, signing/capabilities, data compatibility, ordering and resource ownership when it can still prevent a plausible regression.

Classify records as current, partially superseded, fully superseded, proposed or rejected. Keep partial records linked to their current owner. A live proposal is not an implemented decision. Retain a rejected alternative when the temptation remains relevant; explain what evidence would change the decision.

When the task authorizes consolidation or archiving, transfer unique active rationale to its current owner, preserve historical context in the chosen archive, and repair inbound links. Follow existing immutability rules if the project later adopts them. Do not rewrite a historical record to pretend a proposal shipped, delete useful negative guarantees, or silently drop a translated counterpart.

Report kept, moved, consolidated and proposed removals with evidence and unresolved cases. Do not run nonexistent archive/hash gates or turn a scoped note audit into a code refactor. Use [documentation guidance](../hako-doc/SKILL.md) for current prose and links.
